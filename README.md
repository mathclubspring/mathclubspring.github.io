# Math Club — минимальный каркас Eleventy

Независимый прототип будущего сайта математического клуба. Он не использует контент и файлы действующего Hugo-сайта.

## Подготовка Mac

Для работы нужен Node.js, вместе с которым устанавливается команда `npm`. Если Terminal отвечает `command not found: npm`, установите Node.js через Homebrew:

```sh
brew install node
```

Проверить установку:

```sh
node --version
npm --version
```

## Локальный запуск

В каталоге проекта один раз установите зависимость:

```sh
npm install
```

После этого preview запускается одной командой:

```sh
npm run dev
```

После запуска сайт доступен по адресу, который Eleventy покажет в терминале (обычно `http://localhost:8080`).

## Сборка

```sh
npm run build
```

Готовые HTML-файлы появятся в `_site/`.

Единственная зависимость проекта — Eleventy. Markdown, front matter, шаблоны, коллекции и локальный сервер работают его стандартными средствами.
