Пост посвящён геометрическим задачам для самых маленьких. А именно переходу от двумерных (плоских) к псевдообъёмным конструкциями. Задачи этой подборки несложные, их вполне можно давать дошколятам. Продолжение в виде объёмных задач, рисования конструкций из кубиков и топологии для малышей в следующих постах.

## Подсчёт количества верёвочек (1-2 классы)
Следующее задание взято с сайта https://mathpickle.com/. Задачи крайне медитативные, особенно если взять приятные для работы карандаши.

Когда я замечаю ученика, у которого задачи идут хорошо, то предлагаю перед тем, как начать красить, попробовать определить ответ на глаз.

Исходники заданий и ответы можно найти [тут](https://mathpickle.com/wp-content/uploads/2016/10/Celtic-Counting.pdf), а версию для печати можно найти по ссылке ниже.

## Складываем узлы (1 класс)
Для выполнения следующих заданий детям понадобится верёвочка (например, отлично подойдёт паракорд). В каждом из заданий ученику нужно сложить верёвочку так, чтобы получился нарисованный узел.

[1 класс Складываем узлы](https://docs.google.com/document/d/1pzYR5QygUiqaOeAD3Rc2UFFowlhx5QDcgiRGZ4BSG3Y/edit?tab=t.0#heading=h.zhumndu7ngm4)

## Задача про ёлки (4-7 классы)
Задача 4 класса с олимпиады лицея С.Н. Нюберг.

Егор повесил на каждую ёлку по 4 разные игрушки, затем сделал по три снимка каждой ёлки, после чего снимки перепутались. Распредели все фотографии ниже так, чтобы в одной группе были снимки одной и той же ёлки с разных сторон.

![Иллюстрация 1 к материалу «Узлы и слои (1-3 классы)»](/assets/materials/knots-and-layers/uzs1.png)

Разбор этой задачи можно найти [тут](https://t.me/mathfromnowhere/275).
